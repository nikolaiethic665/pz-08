## Цель

Выбирать теги по смыслу содержимого.

## Задание

Разметить шапку, навигацию и содержимое семантическими тегами.

## Реализация

Заменил общие контейнеры тегами, которые называют назначение блока. Шапка, меню и основное содержимое теперь выделены явно. Каждая заметка — самостоятельный article. Классы сохранились, поэтому стили продолжают применяться. Ссылки меню используют прежние идентификаторы.
